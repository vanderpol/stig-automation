# RHEL 9 V2R9 Anti-STIG Control Matrix

Authority: DISA Red Hat Enterprise Linux 9 STIG V2R9. Current rule count: **445**. V2R9 removed RHEL-09-255130 and added no replacement rule.

This matrix is deliberately independent of SCAP content. The current rule inventory is reconciled from the DISA release/version delta plus the public non-SCAP RHEL 9 Ansible implementation inventory; SCAP/OVAL/XCCDF test logic is not used to select Anti-STIG values.

## Current implementation accounting

- **EXPLICIT-ANTI: 191** — a task intentionally changes state to create the finding, subject to applicability.
- **EXCLUDED: 37** — deliberately not forced because it crosses the recovery/access/site-ownership boundary. Details are in EXCLUSIONS.md.
- **EXPECTED/ASSESS: 217** — environmental/manual/N/A, likely already noncompliant on a fresh installation, or awaiting first lab evidence before adding another state change.

These are implementation statuses, **not SCC results**. A tagged anti-control can still be N/A or assess differently on a particular RHEL 9.x build.
